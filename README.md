# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 技术栈

React + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62007

## 库房盘点闭环

在原入库功能上补齐了单柜盘点闭环，代码按职责拆为三个业务文件：

- `src/model.ts` — 数据模型（标本、柜位、盘点单、差异）、localStorage 持久化与种子数据
- `src/stocktake.ts` — 盘点规则（冻结、暂挂、双人确认、结项、导出限制等纯函数）
- `src/pages.tsx` — 入库队列、筛选、采集地点信息卡、柜位记录、盘点台、单份标本详情页

盘点规则：

1. **单柜冻结**：对某柜位发起盘点后仅冻结该柜位的新上柜（录入直选与队列入柜均拦截），其他柜位照常。
2. **整柜暂挂**：任一份标本被标记为失联或柜位不符即整柜暂挂；存在未盘标本或未放行差异时结项被拒绝。
3. **差异双人确认**：差异须登记原因并经另一名盘点员确认才能放行；缺原因、缺确认人、确认人与发起人相同均拒绝。放行后记录固化为历史凭证；登记草稿在刷新后保留。
4. **结项解冻**：全部盘点且差异全部放行方可结项；结项即解冻柜位并更新盘点时间，按处置方式落账（失联/找回/移回/更正柜位）。
5. **失联留痕**：确认失联的标本置为失联、保留最后已知柜位与盘点历史，禁止导出（CSV 自动排除），其他标本照常导出。
6. **只存浏览器本地**：全部数据存于 localStorage（键 `hxyfront-62007-herbarium-v1`），刷新保留；页脚可恢复演示数据。
