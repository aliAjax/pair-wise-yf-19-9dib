# hxyfront-62007 植物标本馆入库

源提示词编号：9

开发一个植物标本馆压制标本入库前端项目，工作人员可以录入采集号、物种名称、采集地点、海拔、生境描述、采集人、压制状态、鉴定状态和馆藏位置。页面需要有入库队列、鉴定状态筛选、采集地点信息卡、馆藏柜位记录和单份标本详情页。

## 技术栈

React + Vite + TypeScript，数据仅保存在浏览器 localStorage（`herbarium.store.v1`），无后端，刷新页面后数据保留；顶栏「重置为演示数据」可恢复初始演示数据。

## 业务文件划分

| 文件 | 职责 |
| --- | --- |
| `src/herbarium/model.ts` | 数据模型：标本/柜位/差异/盘点会话类型、localStorage 仓库（`createStore`）、入库建档 |
| `src/herbarium/inventory.ts` | 盘点规则：纯函数实现冻结、清点、差异放行、结项门禁、导出剔除等全部业务规则 |
| `src/herbarium/pages.tsx` | 页面：筛选、入库表单、入库队列、馆藏柜位记录与盘点工作台、采集地点信息卡、盘点历史、标本详情页 |

`src/App.tsx` 仅负责组装仓库与页面。

## 库房盘点闭环规则

1. 任一柜位可由盘点员发起单柜盘点；盘点开始后**仅冻结该柜新上柜**，入库时无法选择该柜，其他柜位照常。
2. 每份应盘标本清点为「一致 / 失联 / 柜位不符」。出现任一份失联或柜位不符，整柜自动**暂挂**。
3. 差异必须填写**原因**，并由**另一名盘点员**（不得是发起人本人）确认才能放行；缺原因、缺确认人、本人确认一律拒绝。
   - 柜位不符放行时须选择「按实见位置更新柜位」（目标柜处于盘点冻结时拒绝移入）或「归回台账原位」。
   - 失联放行后标本保持失联状态。
4. 有未清点标本或未放行差异时**不能结项**；结项后柜位解冻并写入盘点时间。
5. 失联标本**禁止导出**（CSV 导出自动剔除），差异记录与标本历史轨迹在本地永久保留。
6. 筛选、柜位记录、盘点状态、详情页共享同一份仓库数据，任何操作即时同步。
